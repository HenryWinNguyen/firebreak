## Goal
Three small FastAPI services that call each other, use Postgres and Redis, and
expose the exact metrics and log format in CONTRACTS §2. They boot with
`docker compose up` through `shopfloor/compose.yml`.

## Mandatory reading
- `CLAUDE.md`, `docs/CONTRACTS.md` §2 (all of it), `docs/ARCHITECTURE.md` §1
- `docker-compose.yml` (root; it includes your `shopfloor/compose.yml`)

## Patterns to mirror
- `firebreak/api/app.py` for FastAPI style. `pyproject.toml` for ruff/mypy settings
- Sentry Load's guinea-pig app idea: a fast path and a deliberately flawed path

## Definition of done
- [ ] `shopfloor/` is its own uv project (`shopfloor/pyproject.toml`) with a shared `shopfloor/common/` package for metrics middleware, JSON logging and admin auth
- [ ] gateway `GET /api/products` and `POST /api/orders` work end to end through orders → inventory, with Postgres rows and Redis used for a product cache
- [ ] Every service exposes `/healthz`, `/metrics`, `app_info{service,version}` and the metric names and labels in CONTRACTS §2.4. `route` is the template, not the raw path
- [ ] Logs are one JSON object per line with the CONTRACTS §2.5 fields. A `trace_id` is propagated through the `X-Trace-Id` header
- [ ] The orders DB pool size is read from a runtime-mutable setting (T-012 will expose it as `orders.db_pool_size`). `db_pool_in_use` and `db_pool_size` are exported
- [ ] `shopfloor/compose.yml` defines gateway (8100), orders (8101), inventory (8102) and redis. It reuses the root `postgres` service and creates the `shopfloor` database through an init step
- [ ] Tests in `shopfloor/tests/`: metrics labels, the log format, the order happy path (DB and Redis faked or via testcontainers-free fakes)
- [ ] No silent failures: downstream errors propagate as 5xx with an `error` log line

## Verify command
```bash
cd shopfloor && uv run pytest -q && cd .. && docker compose up -d --build && \
  curl -sf localhost:8100/api/products && curl -s localhost:8101/metrics | grep -q 'http_requests_total{' && docker compose down
```

## Out of scope
- Chaos flags and `/admin/*` behavior beyond a stub router (T-012)
- Prometheus, Grafana and alert rules (T-013)
