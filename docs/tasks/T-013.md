## Goal
`ops/compose.yml` brings up Prometheus, Alertmanager, Loki (+ a log shipper for
the Docker container logs) and Grafana. They scrape and collect the Shopfloor
services, and alerts route to the Firebreak webhook exactly as in CONTRACTS §3.

## Mandatory reading
- `docs/CONTRACTS.md` §2.1, §2.4, §2.5, §3; root `docker-compose.yml`
- Sentry Load's `ops/prometheus.yml` and `ops/grafana-dashboard.json` (`~/Desktop/Projects/sentry-load/ops/`) for style

## Patterns to mirror
- Pin every image to an exact version tag (no `latest`)

## Definition of done
- [ ] Prometheus scrapes gateway, orders and inventory on the ports in CONTRACTS §2.1 (targets may be down until T-011 merges; config must still be valid)
- [ ] `DBPoolSaturated` only for services with a pool (`orders`, `inventory`). The gateway exports `db_pool_size=0`
- [ ] Alert rules for every row in CONTRACTS §3.1, with the required labels and annotations. Unit tests in `ops/tests/` using `promtool test rules`
- [ ] Alertmanager routes everything to `http://api:8000/webhooks/alertmanager` with bearer auth from env, `group_wait 10s`, `group_interval 30s`
- [ ] Loki collects container stdout. Logs are queryable by `service` label
- [ ] Grafana is provisioned with Prometheus + Loki datasources and a "Shopfloor overview" dashboard (RPS, error rate, p95, pool usage, memory)
- [ ] `ops/README.md`: how to open each UI and how to test a rule

## Verify command
```bash
docker run --rm -v "$PWD/ops:/ops" --entrypoint promtool prom/prometheus:<pinned> check config /ops/prometheus/prometheus.yml && \
docker run --rm -v "$PWD/ops:/ops" --entrypoint promtool prom/prometheus:<pinned> test rules /ops/tests/*.yml && \
docker compose up -d && sleep 20 && curl -sf localhost:9090/-/ready && curl -sf localhost:9093/-/ready && curl -sf localhost:3100/ready && docker compose down
```
