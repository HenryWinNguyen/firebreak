## Goal
An automated check that turning on S1–S4 makes the expected alert reach
Alertmanager, and that resetting clears it. This is the M1 "done when"
criterion in SCOPE.md.

## Mandatory reading
- `SCOPE.md` milestones table (M1), `docs/CONTRACTS.md` §2.3, §3.1

## Patterns to mirror
- `tests/scripts/test_check_owned_paths.py` for pytest style

## Definition of done
- [ ] `tests/integration/m1/test_scenarios.py`, marked `@pytest.mark.integration` (skipped unless `FIREBREAK_INTEGRATION=1`)
- [ ] For S1–S4: reset → apply the fault → generate traffic (a simple async load loop is fine) → poll the Alertmanager API until the expected `alertname` + `service` is firing (timeout 5 min) → reset
- [ ] Expected mapping: S1→HighErrorRate/orders, S2→DBPoolSaturated or HighLatencyP95/orders, S3→HighLatencyP95/orders, S4→HighErrorRate/orders or ServiceDown/inventory
- [ ] A short result table is printed at the end

## Verify command
```bash
docker compose up -d --build && FIREBREAK_INTEGRATION=1 uv run pytest -q tests/integration/m1 -s; docker compose down
```
