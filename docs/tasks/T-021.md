## Goal
`POST /webhooks/alertmanager` and `POST /webhooks/generic` authenticate,
normalize the payload into `Alert`s, drop duplicates, and hand each new alert
to an `IncidentGrouper`.

## Mandatory reading
- `docs/ARCHITECTURE.md` §3, §12; `docs/CONTRACTS.md` §1, §3.2; `firebreak/models/{alert,incident}.py`
- `firebreak/db/` from T-022

## Patterns to mirror
- `firebreak/api/app.py`. Repositories from T-022

## Definition of done
- [ ] Bearer token auth (`Settings.webhook_token`), compared in constant time. 401 on a missing or bad token
- [ ] `normalize.py`: `AlertmanagerWebhook` → `list[Alert]`. Severity and service come from labels, summary from annotations. A missing `service` label → 422 with a clear error, never silently dropped
- [ ] `pipeline.py`: `ingest(alerts, repo, grouper) -> list[GroupingDecision]`. Duplicates (via `insert_if_new`) are reported with `duplicate=True` and not sent to the grouper
- [ ] The response lists the decisions per alert. Replaying the same webhook is a no-op (tested)
- [ ] The grouper is injected via a FastAPI dependency. Tests use a fake grouper
- [ ] Resolved alerts are stored but don't open incidents
