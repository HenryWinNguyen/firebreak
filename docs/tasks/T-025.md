## Goal
Close the minor gaps the independent review found in T-022 before more code depends on them.

## Mandatory reading
- `CLAUDE.md`; `docs/tasks/T-022.md`; `firebreak/db/`; `tests/db/`

## Patterns to mirror
- The existing repositories and typed errors (`PersistenceError` subclasses)

## Definition of done
- [ ] The test fixture refuses to run (hard error, not a skip) unless the database name in `FIREBREAK_TEST_DATABASE_URL` ends in `_test`. This stops `DROP SCHEMA` from ever hitting a dev DB
- [ ] When `FIREBREAK_TEST_DATABASE_URL` is unset, the skip reason says how to set it. CI keeps running them
- [ ] `PostgresEvidenceSink.record`: an idempotent retry (same id + same incident + same raw) returns normally. A conflicting retry (same id, different incident or different raw) raises a typed `EvidenceConflictError`
- [ ] `attach_alert` with an unknown alert id raises `AlertNotFoundError` (not a raw `IntegrityError`), with a test
- [ ] Repository methods that take `now`/datetimes reject naive datetimes with `ValueError`, with a test. Add a non-UTC-offset boundary test
- [ ] **Shared DB fixtures:** move the Postgres fixtures (schema-from-migration, TRUNCATE between tests, `db`-marker skip hook) from `tests/db/conftest.py` to `tests/conftest.py` so every test package uses one copy. TRUNCATE must cover every table, `evidence_blobs` included. The `_test` name guard lives there
- [ ] **Session-taking repository variants** for callers that need several operations in one transaction (from the T-023 review): `AlertRepository.insert_if_new_in(session, alert) -> str` (returns the stored id, existing or new), `IncidentRepository.find_open_for_cluster_in(session, cluster, now, *, for_update: bool)`, `create_in(session, incident)`, `attach_alert_in(session, incident_id, alert_id, service)`, and `update_rollup_in(session, incident_id, *, severity, window_closes_at, services)`. The existing methods become thin wrappers that open a session and call these, so there's exactly one copy of each query
- [ ] `AlertRepository.mark_resolved(idempotency_key, ended_at) -> bool` (+ `_in` variant): sets `status=resolved` and `ended_at` on a stored firing alert. Returns False if there's no such alert. Idempotent
- [ ] A test that runs alembic `compare_metadata` against `tables.py` and asserts no drift
