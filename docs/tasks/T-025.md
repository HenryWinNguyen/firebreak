## Goal
Close the minor gaps the independent review found in T-022 before more code depends on them.

## Mandatory reading
- `CLAUDE.md`; `docs/tasks/T-022.md`; `firebreak/db/`; `tests/db/`

## Patterns to mirror
- The existing repositories and typed errors (`PersistenceError` subclasses)

## Definition of done
- [ ] The test fixture refuses to run (hard error, not a skip) unless the database name in `FIREBREAK_TEST_DATABASE_URL` ends in `_test`. This stops `DROP SCHEMA` from ever hitting a dev DB
- [ ] When `FIREBREAK_TEST_DATABASE_URL` is unset, the skip reason says how to set it. CI keeps running them
- [ ] `PostgresEvidenceSink.record`: an idempotent retry (same id + same incident + same raw) returns normally. A conflicting retry (same id, different incident or different raw) raises a typed `EvidenceConflictError`
- [ ] `attach_alert` with an unknown alert id raises `AlertNotFoundError` (not a raw `IntegrityError`), with a test
- [ ] Repository methods that take `now`/datetimes reject naive datetimes with `ValueError`, with a test. Add a non-UTC-offset boundary test
- [ ] A test that runs alembic `compare_metadata` against `tables.py` and asserts no drift
