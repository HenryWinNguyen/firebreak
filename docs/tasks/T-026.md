session-taking repository methods from T-025, and gain the edge-case tests the review asked for.

## Definition of done
- [ ] The grouper keeps its advisory lock + single transaction but does every read/write through the `*_in` repository methods. No raw SQL or row construction remains in `grouping.py`
- [ ] Delete the copied DB fixtures from `test_grouping.py`. Use the shared `tests/conftest.py`
- [ ] A resolved alert never opens an incident or moves a window. It's stored and, if an open incident exists for its cluster, attached without severity/window effects (defense in depth; ingest already filters them)
- [ ] The unknown-service warning logs once per service per process, not on every alert
- [ ] Tests: exclusive boundary (`now == window_closes_at` → new incident), a terminal incident is never joined, the same alert delivered twice concurrently → one link + one `duplicate=True`, an alert pre-inserted by ingest but unlinked gets grouped, resolved-alert behavior
