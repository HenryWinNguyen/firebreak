## Goal
An `AnthropicLLMClient` that implements `LLMClient`, plus a `ReplayLLMClient`,
so agents and evals run deterministically and for free in CI.

## Mandatory reading
- `docs/ARCHITECTURE.md` §5.3; `firebreak/models/llm.py`
- Use the **claude-api skill** for current model ids, pricing, prompt caching and the error types. Don't guess prices or ids

## Patterns to mirror
- Pydantic models from `firebreak/models/llm.py` at every boundary. Settings in `firebreak/llm/settings.py` (`FIREBREAK_LLM_*`)

## Definition of done
- [ ] Converts `LLMRequest` ↔ the Anthropic Messages API. Adds `cache_control` to the system prompt and tool definitions
- [ ] Retries with jittered exponential backoff on 429, 5xx and overloaded errors (max 4). Falls back to `fallback_model` if one is given after retries run out. Non-retryable errors raise a typed `LLMError` and are never swallowed
- [ ] `Usage.cost_usd` is computed from `firebreak/llm/pricing.yaml` (with source + date noted in the file)
- [ ] An in-process async token-bucket limiter (requests/min, configurable)
- [ ] `FIREBREAK_LLM_MODE=live|record|replay`: the fixture key is a sha256 of the canonical JSON of (model, system, messages, tools). Fixtures are JSON in a configurable dir. Replay on a missing fixture raises `FixtureMissing` with the key
- [ ] Tests use a fake HTTP transport (no network): retry, fallback, cost math, record→replay round trip, missing fixture

## Verify command
```bash
make test-llm && make typecheck
```

## Out of scope
- A global (cross-process) rate limiter; streaming
