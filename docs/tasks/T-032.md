## Goal
The bounded tool-use loop every Firebreak agent runs (ARCH §5.1) and the single
chokepoint every tool call goes through (ARCH §6). It's built against the
`LLMClient` and `EvidenceSink` Protocols, so it doesn't wait on T-031 or T-022.

## Mandatory reading
- `docs/ARCHITECTURE.md` §5, §6, §8 (all of them); `firebreak/models/{llm,agents,evidence}.py`

## Patterns to mirror
- Protocols from `firebreak/models/`. Fakes for `LLMClient` and `EvidenceSink` live in `tests/`

## Definition of done
- [ ] `agents/config.py` loads and validates `configs/*.yaml` into `AgentConfig`. An unknown tool or output schema fails at load time
- [ ] `tools/registry.py`: tools are declared with a pydantic args model + an async handler + `ToolAccess`. `ToolSpec.input_schema` is generated from the args model
- [ ] `tools/gateway.py` `invoke(agent_cfg, tool_name, raw_args, ctx)`: allowlist → args validation → **WRITE tools always refused** → timeout → handler → size-cap → `EvidenceSink.record` → result wrapped in an untrusted-data block → `ToolCallRecord`. Every refusal is a typed error returned to the model as a tool error, never a crash and never silent
- [ ] `agents/runtime.py` `run_agent(cfg, task, ctx, llm, gateway) -> AgentRunResult`: loop up to `max_steps`, run parallel tool calls with `asyncio.gather`, stop on budget (`Usage.cost_usd > budget_usd`), parse the final output into `output_schema` with **one** repair turn, and validate that every cited `evidence_id` exists via `EvidenceSink.exists`
- [ ] Tests with a scripted fake LLM: happy path, max_steps, budget stop, repair-turn success and failure, a hallucinated evidence id is rejected, a non-allowlisted tool, a WRITE tool refused, a tool timeout, and injection text in a tool result stays inside the untrusted wrapper
- [ ] One example config + prompt (`configs/echo.yaml`) used by the tests
