## Definition of done
- [ ] LLM client honors `LLMRequest.fallback_model` (falls back only to that model, only on the
      error classes already treated as retryable/overloaded). No built-in sonnet→haiku default
      fallback remains. Test: fallback used when set, never when unset.
- [ ] Price lookup for a model missing from `pricing.yaml` falls back to the price of the model
      *that API call requested* (lead ruling: for the fallback call that is the fallback model, which is what served it); an unknown model logs a warning once and counts the cost as NaN
      so the runtime's budget check (non-finite = over budget) trips. Test.
- [ ] Record/replay fixture writes are atomic (temp file + `os.replace`). Test.
- [ ] `max_retries=0` makes exactly one attempt. Test.
- [ ] `Retry-After` (seconds or HTTP date) is honored on 429/529, capped by the existing max backoff. Test.
- [ ] Runtime: a tool task that ends up `cancelled()` after the TaskGroup without the run itself being
      cancelled (a handler that cancels its own task) becomes that call's `internal_error` result
      instead of raising `CancelledError` out of `run_agent`. Test with a self-cancelling handler:
      exactly one tool_result per tool_use, run continues.
- [ ] `_run_tools` docstring states accurately which path yields `handler_failed` (gateway) vs
      `internal_error` (stray CancelledError outside the gateway).
- [ ] No silent failures: every caught exception is re-raised, logged with context, or turned into a typed error
- [ ] PR description has a `## Progress entry` (builders don't edit PROGRESS.md)
