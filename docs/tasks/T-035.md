## Definition of done
- [ ] Guard transport compares `request.url.raw_path` (without the query) against the allowlist, and pins
      scheme + host + port to the adapter's configured base URL. Tests: `admin%2Fdeploys` refused, a
      different host refused (and the bearer token is never sent to it).
- [ ] Response size cap in `get_json` before parsing (`Content-Length` when present, else bytes read, streamed
      with a hard stop at ~4 MB) → typed error "response too large; narrow the query". Test.
- [ ] Bare `NaN`/`Infinity` literals in a backend JSON body are rejected (`parse_constant`) as a typed backend
      error, so the stored evidence blob is always valid JSON. Test.
- [ ] Time windows are truncated to whole seconds before both the request and `Evidence.query`, so the
      recorded query reproduces the exact window. Test with a clock that has microseconds.
- [ ] A backend timeout reaches the model as `timeout` (map the adapter's `BackendTimeout` to the gateway's
      timeout code), and `test_timeout_every_backend` asserts that.
- [ ] Per-tool coverage: backend error + HTTP 500 for `promql_range`, `list_metrics`, `recent_deploys`;
      truncation for `promql_query`, `recent_deploys`; `"NaN"`/`"+Inf"` string values rendered verbatim;
      downsampling determinism.
- [ ] No silent failures
- [ ] PR description has a `## Progress entry` (builders don't edit PROGRESS.md)
