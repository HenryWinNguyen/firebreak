## Goal
SCOPE M3 "done when": the baseline runs S1–S7 on the live stack and produces a root-cause answer
for each. Recordings from this run seed the M4 replay fixtures.

## Gate
**Always-stop (AGENT_WORKFLOW §6.2): paid service + secret.** Needs `ANTHROPIC_API_KEY` in `.env`
(Henry) and Henry's OK on spend. Estimate: 7 scenarios × ≤ $0.50 budget cap = ≤ $3.50 per full run,
plus ≤ 1 re-run.

**Why it waits for T-044/T-045:** without tool cassettes and deterministic ids, recordings can't be
replayed, so the spend would only produce a one-off table. An optional S1 smoke run (≤ $0.50) can go first.

## Definition of done
- [ ] For each of S1–S7: apply the fault (reuse the T-014 helpers), wait for the alert → incident,
      run `python -m firebreak.evals run --mode record` (T-045), store the report, reset.
- [ ] A results table (scenario → expected category → top-1 → in top-3? → cost → latency → steps) in the PR.
      No pass/fail threshold here; accuracy targets are M4's job. Every scenario must produce a report.
- [ ] Recordings committed under `evals/recordings/baseline/`, with no secrets in them.
