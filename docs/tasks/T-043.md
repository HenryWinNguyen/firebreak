## Goal
Ground truth as data and a pure, deterministic grader (ARCH §9) that scores an
`InvestigationReport` against a scenario. No LLM, no DB, no network.

## Mandatory reading (before writing any code)
- `CLAUDE.md`, `SCOPE.md` (success criteria + scenario table), `docs/ARCHITECTURE.md` §9
- `docs/CONTRACTS.md` §1–§3 (flags, alerts, `InvestigationReport`)
- `firebreak/models/reasoning.py`, `firebreak/models/evidence.py`, `firebreak/agents/baseline.py` (`BaselineResult`)
- `tests/integration/m1/test_scenarios.py` (how S1–S4 are applied today)

## Definition of done
- [ ] `firebreak/evals/scenario.py`: a Pydantic `Scenario` (extra="forbid") loaded from YAML:
      `id`, `title`, `setup` (chaos flags, optional deploy `{service, version}`), `load` (rps, duration_s,
      cart size), `expect` (`alerts`: list of `{alertname, service}` any-of; `root_cause_category`;
      `must_cite_kinds`: list[EvidenceKind]; `action`: ActionType | None; `action_target`: str | None),
      `teardown`. `load_scenarios(dir) -> dict[id, Scenario]` fails loudly on a bad file or duplicate id.
- [ ] `evals/scenarios/s01.yaml` … `s07.yaml` for S1–S7 from the SCOPE table and CONTRACTS §2.3
      (S5 `orders.leak_kb_per_request`, S6 `orders.redis_host`, S7 load only). Ground truth is the SCOPE
      "expected root cause" column, mapped to `RootCauseCategory`.
- [ ] `firebreak/evals/grader.py`: `grade(scenario, report: InvestigationReport | None, *, evidence_kinds:
      dict[evidence_id, EvidenceKind], usage_usd: float, latency_s: float, error: str | None) -> Grade`
      with fields: `top1` (bool), `top3` (bool), `cited_kinds_ok` (every `must_cite_kinds` kind is cited by
      some finding that supports the top-1 hypothesis), `report_valid`, `cost_usd`, `latency_s`, `error`.
      A missing report grades as all-false with the error kept (never raises).
- [ ] `summarize(grades) -> Summary`: top-1 and top-3 accuracy, p50/p95 latency and cost, error count.
- [ ] Tests: each scenario file loads; bad YAML / unknown field / duplicate id fail; grader cases for top-1 hit,
      top-3-only hit, miss, `unknown` category, missing report, cited-kinds satisfied vs not, summary percentiles
      on known inputs.
- [ ] No silent failures
- [ ] PR description has a `## Progress entry` (builders don't edit PROGRESS.md)
