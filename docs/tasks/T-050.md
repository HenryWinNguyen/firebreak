## Goal
Ollama silently truncates a prompt that exceeds the server's context window (`OLLAMA_CONTEXT_LENGTH`, default
4096) and still answers. A truncated conversation would produce a wrong-but-plausible eval score. Make overflow
a loud, typed failure instead.

## Mandatory reading (before writing any code)
- `CLAUDE.md`, `docs/tasks/T-047.md`, `firebreak/llm/{openai_compat,settings,errors}.py`
- `firebreak/agents/runtime.py` (how LLM errors end a run)

## Definition of done
- [ ] Setting `FIREBREAK_LLM_OPENAI_CONTEXT_TOKENS` (int, default 32768, documented: must equal the server's
      `OLLAMA_CONTEXT_LENGTH`).
- [ ] Before sending: estimate prompt tokens (chars of system + messages + tool schemas / 3, documented as a
      conservative estimate). If `estimate + max_tokens > context_tokens`, raise `ContextOverflowError` (new, a
      subclass of the existing LLM error base, not retried) without sending.
- [ ] After a reply: if `usage.prompt_tokens + usage.completion_tokens >= 0.98 * context_tokens`, raise
      `ContextOverflowError` (the server almost certainly truncated). The message names the model, the token
      counts and the setting, and says to raise `OLLAMA_CONTEXT_LENGTH` and the setting together.
- [ ] The Anthropic client is unchanged.
- [ ] Tests (`httpx.MockTransport`, no network): pre-flight refusal sends no request; post-reply detection;
      normal-size requests unaffected; the error is not retried; the message content.
- [ ] No silent failures
- [ ] PR description has a `## Progress entry`

uv run pytest -q tests/llm && make check

## Out of scope
- Truncating or summarizing history to fit (a later prompt/runtime task if overflow is common).
- Any real network call.
