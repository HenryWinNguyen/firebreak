## Goal
In S3 (N+1), every order makes one DB round trip per cart item. This holds the connection longer, so
`DBPoolSaturated` fires next to `HighLatencyP95`, which looks the same as S2 (pool exhaustion) in every
metric orders exports today. In T-049 the baseline answered `resource_exhaustion` instead of `slow_query`.
Add the signal a good SRE would look at: DB queries per request.
