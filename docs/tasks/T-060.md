## Goal
T-059's review left three minors on the `replay` job before it becomes a required check: the ci.yml comment says
it fails on "any error" (it fails on a stale recording or a setup error; graded misses and invalid answers exit 0),
the job has no `timeout-minutes`, and a stray directory under `evals/recordings/` (one that holds no recordings)
turns `make eval AGENT=all` red.

- `CLAUDE.md`, `docs/tasks/T-059.md`

## Definition of done
- [ ] `make eval AGENT=all` replays only agent dirs that contain at least one recording (`<dir>/*/meta.json`), and
      prints one `skip <dir>: no recordings` line per skipped dir. It still exits 1 if no dir has recordings. An
      explicit `AGENT=<dir>` is unchanged (an empty or unknown dir still fails loudly)
- [ ] A dir that does hold recordings but names an unknown agent still fails (don't hide it)
- [ ] `replay` job: `timeout-minutes: 15`; the comment says exactly what fails it (stale recording, missing fixture,
      unknown agent, setup error) and what doesn't (graded misses, invalid final answers)
- [ ] Verified: `make eval AGENT=all` locally with an extra empty-ish dir (e.g. `evals/recordings/tmp/README`)
      skips it and passes; remove the dir before committing. Describe it in the PR
- [ ] PR description has a `## Progress entry`

## Verify command
```bash
make eval AGENT=all && make check
```
