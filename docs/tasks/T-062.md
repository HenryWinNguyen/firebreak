## Goal
Review minors left on T-054 and T-057:
1. The synchronous RSS check before `gen.start()` (live.py ~716) only proves Prometheus is readable; it doesn't compare
   against `max_orders_rss_mb`, so load starts on an orders that is already over the limit and the first guard poll
   trips. It should refuse to start instead.
2. The `rss_guard` docstring / module docstring imply the blind bound is the grace; the real bound is about
   grace + poll interval + the HTTP timeout. Say so.
3. Two T-054 tests are timing-tight or indirect (`test_rss_blind_gap_shorter_than_grace_is_survived`,
   `test_rss_good_read_resets_blind_clock`). Make them deterministic (inject the clock / drive polls explicitly rather
   than relying on wall time), without changing guard behaviour.
4. T-057's old-format replay test patches `deterministic` during replay as well, so it doesn't prove a real
   old-format recording (meta.seed == scenario id) replays. Add a small golden old-format recording fixture and replay
   it unpatched.
